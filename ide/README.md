# Rake IDE

TurboWarpのScratchエディターをベースにしたRakeの開発環境です。画面は左から「Scratchのブロック／コスチューム／音」「Rakeのコードエディター（Monaco + Rake Language Server）」「ステージとスプライト一覧」の3列です。

## セットアップと起動

Rust (Cargo)、[Bun](https://bun.sh/) 1.4以降、Gitが必要です。Node.jsとnpmは使いません。

```sh
cd ide
bun run setup   # TurboWarp scratch-guiを取得・ビルドし、サーバー依存とRakeのバイナリを用意
bun start       # http://localhost:8610/ を開く
```

`bun run setup` は TurboWarp/scratch-gui の固定コミットを `ide/gui/scratch-gui` に取得し（Gitには含めません）、`ide/gui/overlay` のファイルを追加し、`ide/gui/patches/*.patch` を適用してから、Bun上でwebpackを動かしてビルドします。依存関係は `bun install` で入れ、TurboWarpの `package-lock.json` をBunの形式に変換するため、npmと同じバージョンになります。ただし、TurboWarpのGitHubフォーク（scratch-renderなど）に付いているnpm用の整合性ハッシュはBunが取得するアーカイブと一致しないので、これだけは削除します。これらのパッケージはコミットで固定されたままです。IDEのコードだけを変更した場合は `bun run build:gui` で再ビルドできます。

プロジェクトは `~/RakeProjects`（環境変数 `RAKE_PROJECTS_DIR` で変更可）に保存されます。初回起動時に空ならサンプルプロジェクトを作ります。ポートは `PORT`、コンパイラーと言語サーバーは `RAKE_BIN` / `RAKE_LSP_BIN` で指定でき、未指定ならリポジトリの `target/` にある新しい方のビルドを使います。サーバーは `127.0.0.1` だけで待ち受け、他サイトからの書き込み要求とWebSocket接続を拒否します。

## 機能

- **レイアウト**: ツールバー右端で3つのモードを切り替えます（選択は保存されます）。
  - **分割**: ブロック・コードエディター・ステージを横に並べます。コードパネルは左端をドラッグして幅を変えられます。
  - **ブロック**: コードエディターを隠し、Scratchのブロック画面を広く使います。画面端の縦のボタンで他のモードに戻れます。隠している間もライブビルドは動き、ビルドに失敗すると ⨯ を表示します。
  - **コード**: コードエディターがScratchのブロック／コスチューム／音の場所を使い、コードとステージだけを表示します。
- **リアルタイムコンパイル**: 編集後、指定した待ち時間（300〜2000 ms）が経つと自動保存してアクティブなシーンをコンパイルし、ステージに読み込みます。`Ctrl+Enter` で即時ビルド、`Ctrl+S` で保存します。「ライブ」を外すと自動ビルドしません。⚑ をオンにすると、実行中にビルドした場合に緑の旗を押し直します。編集中のスプライトは再読み込み後も選択したままです。
- **言語サーバー**: 診断、補完、ホバー、定義へ移動（別ファイルも開きます）、参照、名前変更、アウトライン、セマンティックハイライトに対応します。`.rks` ではプロパティやファイルパスの補完も使えます。ランタイムはシーン直下の `runtime: "scratch"` / `runtime: "turbowarp"` で選択でき、既定値はScratchです。ビルド時のエラー（シーン全体の検査など）も「問題」に表示します。
- **プロジェクト管理**: 作成、切り替え、複製、名前変更、ゴミ箱への移動（`<プロジェクト>/.trash` / `RakeProjects/.trash`）、.sb3のダウンロード。ファイル一覧ではファイル・フォルダーの作成、名前変更、ゴミ箱への移動、アセットのアップロード、画像と音声のプレビューができます。
- **.sb3の読み込み（実験的）**: ☰ メニューの「.sb3を読み込む（逆コンパイル・実験的）…」で既存の `.sb3` を選ぶと、`rake decompile` でシーン・`.rk`・アセットに変換して新しいプロジェクトとして開きます。変換できなかったブロックは `// [decompile]` コメントとして残り、警告は「出力」に表示します。変換の制限は[ルートのREADME](../README.md#sb3からの逆コンパイル実験的)を参照してください。
- **シーン管理**: 「シーン」タブでシーン（`.rks`）の切り替え（▶）、新規作成、複製、名前変更、削除、メインシーン（★、`rake-ide.json` の `mainScene`）の設定ができます。
  - **ステージ → シーン**: TurboWarp上でスプライトをドラッグしたり、コスチュームを描いたり、スプライトを追加したりした結果をシーンファイルへ書き出します。コスチュームと音は `assets/` に保存し（既存の同名アセットはそのパスを再利用）、各ターゲットの `scripts` 割り当てとランタイム指定は維持します。シーンファイルのコメントと書式は作り直されます。
  - **シーン → ステージ**: シーンをビルドしてステージに読み込みます（▶ またはビルドボタン）。

Scratchのブロックエディターで直接作ったスクリプトはRakeのソースに書き戻されません。コードの正本は `.rk` ファイルです。

## テスト

```sh
cd ide && bun run test
```

## ライセンス

`ide/gui` はGPL-3.0のTurboWarp scratch-guiに組み込んで配布されるため、IDE部分はGPL-3.0-onlyとしています。
